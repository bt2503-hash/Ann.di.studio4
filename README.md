# ann.di.studio — сайт + спільна база даних

## Що в папці
| Файл | Призначення |
|---|---|
| `index.html`, `css/site.css` | вітрина (дизайн) |
| `js/shop.js` | каталог, фільтри, кошик, обране, тексти сайту |
| `js/checkout.js`, `js/account.js` | оформлення замовлення, кабінет покупця |
| `js/api.js` | **єдине місце**, де сайт говорить із Supabase |
| `admin.html`, `css/admin.css`, `js/admin.js` | адмінпанель |
| `js/data.js`, `js/i18n.js`, `js/util.js` | стандартні дані, переклади, дрібні функції |
| `supabase-setup.sql` | створює всі таблиці, правила доступу й сховище фото |
| `supabase-config.js` | сюди вставляються ключі Supabase |

## Налаштування (один раз, ~10 хвилин)
1. **Supabase** → New project (безкоштовно).
2. **SQL Editor → New query** → вставити весь `supabase-setup.sql` → **Run**.
3. **Project Settings → API** → скопіювати *Project URL* і *anon public key* у `supabase-config.js`.
   Не використовуйте `service_role`.
4. **Authentication → Providers → Email** — увімкнений. Для тестів можна вимкнути *Confirm email*, для справжнього запуску — залишити.
5. Завантажити всю папку на Netlify (перетягнути).
6. На сайті натиснути іконку профілю → **Реєстрація** (ваш акаунт адміністратора).
7. Supabase → **Authentication → Users** → ваш користувач → **App Metadata**:
   `{ "role": "admin" }` → Save. (User Metadata не чіпати.)
8. Відкрити `/admin.html`, увійти → вкладка **Товари** → **Імпортувати стандартні товари**.
   Після цього всі товари, тексти й фото редагуються в адмінці й одразу видно всім.

## Що тепер у базі
- **Товари** — разом із фото (сховище `media`). Раніше жили лише в браузері адміна.
- **Тексти, фото й контакти сайту** — вкладка «Сайт».
- **Запити з контактної форми** — вкладка «Запити» (раніше нікуди не доходили).
- **Замовлення** — як і раніше, прив’язані до акаунта покупця.

## Безпека
- Покупець бачить лише свої замовлення; змінювати статус може тільки адмін.
- Ціну й суму замовлення перераховує **база** за таблицею товарів — підмінити ціну в браузері не можна.
- Фото й товари змінює лише акаунт із `role = admin`.
- Якщо Supabase не підключений, сайт показує стандартні товари, але замовлення й форма не працюватимуть (навмисно).

## Що змінено порівняно зі старою версією
- Новий дизайн (світла палітра з логотипу), код розбито на зрозумілі файли замість рядків по 3000 символів.
- Прибрано: порожню категорію «Шкіра» в каталозі, фільтр за ціною (більшість товарів «за запитом»), залежність від фото з Unsplash, дублі коду.
- Додано: товари / тексти / запити / фото в базі, перевірку цін на стороні бази, лічильники лише коли не нуль, мобільне меню, доступність (Esc, aria).
- Товари «Ціна за запитом» (ціна 0) не додаються в кошик — їх замовляють через форму.
